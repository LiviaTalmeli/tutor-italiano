# Viare: AI-Powered Language Learning Bot 🤖

An automated Telegram bot built with **Python** and **Flask** that integrates the **OpenAI API** to provide real-time grammar corrections and language feedback to users. 

This project was developed to scale language tutoring, offering students an interactive, on-demand environment to practice and improve their communication skills.

## 🚀 Features
*   **Real-time Grammar Correction:** Processes user text and returns contextual corrections using OpenAI's LLM.
*   **Instant Feedback Loop:** Seamless integration with Telegram via Webhooks/Polling for zero-latency responses.
*   **Scalable Architecture:** Backend structured with Flask, ready for cloud deployment.

## 🛠️ Tech Stack
*   **Backend:** Python 3.x, Flask
*   **APIs:** OpenAI API, Telegram Bot API
*   **Deployment:** Cloud Hosting
*   **Version Control:** Git, GitHub
